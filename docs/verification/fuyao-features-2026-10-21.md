# 扶摇研究功能验收

2026-10-21。对应[实施清单](../design/fuyao-feature-plan.md)。本记录持续更新，以末尾交付状态为准。

## 已实现入口

1. 个股详情新增「情报」页签：新闻、异动解读、24 小时热榜和每日排名走势。空数据、部分失败、日期未知分别处理。
2. 今日工作台「板块强弱」：行业/概念目录、当日涨跌排序、当前成分股和自选交集；选中板块后计算近 5 / 20 个基准交易日相对沪深 300 的涨幅差（百分点）。
3. 今日工作台「ETF 穿透」：按当前账户、币种分别估算 ETF 与直接持股的重合敞口。ETF 详情的情报页展示披露持仓。报告期、覆盖比例及未穿透部分可见。
4. 今日工作台市场情绪卡及详情：涨停、跌停、炸板、封板率、精确连板家数；股票池可筛选自选、加载下一页、查询历史日期。
5. 个股情报页「财报与估值」折叠区：三张报表最近 8 期、最新 5 类估值，显示报告期及披露日。同币种上年同期、正基期才计算同比。
6. 计划详情及交易复盘的「记录时的市场背景」：本机对新计划与当日新增成交冻结已观察到的研究缓存；按账户、标的、记录类型及 UUID 隔离。

## 数据与运行边界

- 所有研究 HTTP 请求复用同一扶摇 actor 的认证和 0.5 秒最小请求间隔，并向已在执行的报价轮次让出下一请求时隙。
- 情报 120 秒、板块与情绪 300 秒、财报及基金披露 3600 秒缓存；财报展开后才查询。成分股用每批 100 只的股票快照，避免逐只类型解析。
- 每秒行情目标仍受单轮耗时、标的数量及服务端动态限流约束，不宣称逐笔或 Level 2。
- 当前成分股不能代表历史归属；5/20 日相对值按基准日历锚点对齐，不压缩交集补齐缺失交易日。
- 基金披露不是实时持仓。未知权重不补零、不归一；未覆盖市值明确列示。空头另列，不与多头抵消；不同币种不合并。
- 股票池保留实际业务日期与采样时间。筛选只覆盖已加载分页；历史查询使用实际统计交易日请求股票池。
- 财报收入与现金流保持累计口径，期末资产负债保持存量口径；过滤未来披露，不将披露日、报告期和获取时间混用。历史修订的完整时点数据库不在本轮范围内。
- 背景留存是独立本机研究缓存，最多保留最近 1000 条，不随账本同步或备份；旧记录、远端应用及历史补录不补造盘面。编辑已有记录不会改写其留存背景。
- UI 只读研究数据，不自动确认计划条件或执行交易；不覆盖手动行业分类。

## 工作模型与环境

- 情报和板块数据层使用 DeepSeek 4.1 Flash 草稿，由主代理修正、集成并完成仓库内测试。
- 后续 Flash 请求遇到 WorkBuddy HTTP 400 / code 11128 渠道校验拒绝，主代理继续完成实现，没有换用其他工作模型。
- 新旧日常 App 的 bundle identifier 与指定签名要求一致；未更换签名证书。最终凭据处理见下述固定组件修复，旧凭据条目保持原样。
- 非交互 Keychain 读取返回 -25293。验收曾临时开启交互读取，导致用户再次遇到系统密码弹窗；该入口及二次读取重试现已全部移除，凭据读取函数本身也强制禁止交互。
- 最终真实接口验收使用此前用户提供的同一 Key，经隐藏输入及匿名内存管道传入隔离进程，不访问或修改 Keychain；Key 未进入源码、文件、参数、worker 或输出日志。
- 线上基金持仓与示例存在差异：`report_type` 返回中文展示名，部分 `thscode` 是裸代码。解析兼容目录展示名，裸代码只有在证券代码和公司名称都与元数据一致且结果唯一时补全市场；否则保留待确认并不计入重合敞口，避免跨市场同代码混淆。

## 重复授权原因与修复

- 只读检查该扶摇条目的 ACL：解密应用已指向日常 FFF，但访问分区仅包含三条 `cdhash`；当前自签开发证书没有 TeamIdentifier。指定签名要求相同仍不足以跨编译保持分区匹配。
- 新增独立、固定签名的 `FFFCredentialBroker`，仅用于本地开发版扶摇。普通编译复用其二进制；清理构建缓存后优先从已验签的日常应用复用。主应用验证组件证书及标识，组件反向验证实际父进程的 `app.pulse.mac.dev` 标识及同一证书。组件继承主应用沙盒，没有独立网络监听或常驻服务。
- 使用此前用户提供的同一 Key，经隐藏输入和内存管道写入组件专用 Keychain 项；旧项未删除、未改 ACL。没有新建证书、信任根或全局分区授权，密钥仍不进入源码、文件、参数和日志。
- 已实测：保存后读回成功；再次编译后主程序指纹变化、组件指纹保持不变，程序无外部输入读回成功；普通命令行直接调用被拒绝，输出 0 字节凭据；同证书但错误应用标识的沙盒测试父进程被组件明确拒绝（exit 77，0 字节凭据）；安装至日常路径后再次静默读取成功。模拟删除组件构建缓存后，从已验签日常版复用的组件与原二进制完全一致。
- 所有读取、保存、删除均禁止交互。后续若修改组件源码、entitlements 或证书，需要显式规划迁移；不能以重新开启密码弹窗处理组件身份变化。
