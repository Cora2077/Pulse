# 同花顺行业指数：免费接入验收

## 交付范围

已在源码中注册 `ThsSectorProvider`，使用免费的 `d.10jqka.com.cn`，不需要 API Key。内置 90 个行业指数；本轮没有扩展概念板块目录。搜索中文名称、常用别名或完整代码均可找到行业指数。

身份保持 A 股时区/币种/交易时段，独立板块标识保证不会把指数误作可持仓股票。路由按具体标识隔离：板块只发给同花顺，普通股票不会被这个源接管；旧版本读新快照仍能保留整个自选列表。
