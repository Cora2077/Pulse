# MCP 本机接口

FFF 内置一个**可选、默认关闭**的 MCP 服务，让本机的 agent（Claude Code、Cursor、DeepSeek Harness 等）读写自选、记账成交和交易计划。

这一页说明它**现在到底能做什么**。判断范围以代码里的工具注册表（`MCPToolAdapter`）为准，**不是以界面支持什么为准**——很多界面功能还没有对应的 MCP 工具。

> **它不是下单通道。** MCP 工具只读写本地账本，不向任何券商发送委托。「记录成交」记录的是**用户已经发生**的交易。

基线：2026-10-04，19 个工具。本文随注册表更新。

## 开启与连接

在「设置 → Agents → MCP」中开启。开启后展开的连接信息里可以复制端点与令牌。

- **端点是 loopback**：只绑定 `127.0.0.1`，局域网内其他设备无法访问。
- **路径固定为 `/mcp`**，非该路径的请求在进入 MCP 传输层之前就被拒绝。
- **必须带 `Authorization: Bearer <token>`**。令牌校验使用常量时间比较；未通过认证的请求不会到达工具层。
- **Origin 受校验**，只接受本机来源。
- **令牌保存在 macOS 钥匙串**中，不在同步文件或源码里，可在设置中轮换；轮换后旧令牌立即失效。

该令牌具有本地写入能力，**不要**提交进仓库、贴进 issue 或测试报告。

## 账号隔离

账号固定为三个：`unassigned`（未归属）、`financing`（融资账号）、`mengmeng`（萌萌账号）。

除以下三个工具外，**所有工具都必须显式给出 `account_id`**：

- `list_brokerage_accounts`（用途就是列出账号）
- `get_quotes`（行情是共享市场数据）
- `search_symbols`（标的搜索是共享市场数据）

遗漏会返回 `account_required`。在启用账号功能之前，`account_id` 是可选参数。

调用某个账号的数据操作**不会改变界面当前选择的账号**——操作结束后界面选择会被恢复。新买入必须落在 `financing` 或 `mengmeng`；落到 `unassigned` 会被拒绝。

## 工具（19 个）

### 只读（5 个）

| 工具 | 作用 | 需要 account_id |
| --- | --- | --- |
| `list_brokerage_accounts` | 列出账号 ID、界面当前账号，以及各账号的记录数量 | 否 |
| `list_watchlists` | 读取自选、分组与排序 | 是 |
| `list_positions` | 读取持仓账本；分配区块、验证与资金来源嵌套在其中 | 是 |
| `get_quotes` | 读取共享的缓存行情 | 否 |
| `search_symbols` | 搜索标的 | 否 |

### 写入（14 个）

| 工具 | 作用 | 限制 |
| --- | --- | --- |
| `add_symbol` / `remove_symbol` | 增删自选 | 按 `account_id` 隔离 |
| `create_group` / `rename_group` / `delete_group` | 分组增改删 | 最后一个分组受保护，返回 `last_group_protected` |
| `reorder_groups` / `reorder_symbols` | 分组与标的排序 | 顺序非法时返回对应错误码 |
| `set_thesis` | 保存用户自己的持有理由（自由文本） | 空字符串表示清除；不参与任何计算 |
| `set_trade_plan` / `delete_trade_plan` | 新建、修改、删除交易计划 | **仅**买卖方向、价格、数量、状态和备注 |
| `record_trade` / `update_trade` / `delete_trade` | 成交录入、修改、删除 | 走与界面相同的校验路径 |
| `calibrate_position` | 持仓校准 | 用于对齐外部持有的数量与成本 |

## 开放范围与缺口

按功能区域看当前覆盖情况：

| 功能区域 | 读取 | 修改 |
| --- | --- | --- |
| 证券账号 | 列出账号；按 `account_id` 读取账号内自选与持仓 | 基础交易、分组、逻辑和计划均按账号隔离；**暂不支持**归属分配 |
| 自选 / 分组 / 排序 / 搜索 | 支持 | 支持 |
| 持仓账本 / 成交 / 校准 | 支持；融资与计划快照部分嵌套在原始数据里 | 支持基础成交字段与校准；**不支持**全部融资和复盘字段 |
| 交易计划 | 有持仓历史的标的可读计划、条件和历史 | 仅基础字段；**尚缺**用途池、融资意图、条件和事件关联的写入口 |
| 仓位池 / 持仓验证 | `list_positions` 可读分配区块、验证与资金来源 | **尚未开放**转移、拆分、资金来源标记、验证编辑、核对与撤销 |
| 事件日历 | 持仓标的的手工事件可随 `list_positions` 读取 | **尚无**事件增删改、时间线和全局事件列表工具 |
| 今日工作台 / 资金预算 / 预演 | **尚无**聚合与预算读取工具 | **尚无**现金、池预算、预演场景工具 |
| 交易复盘 | 成交附带的复盘信息部分可读 | **尚无**复盘与检查点的专用修改工具 |
| 行情 | 读取共享缓存行情；搜索标的 | **尚无**主动刷新、分时/K 线专用工具 |
| 备份 / 同步 / 设置 | **尚无**专用工具 | **尚无**专用工具 |

## 后续补齐顺序

1. 仓位与验证操作
2. 计划执行／条件／事件关联
3. 工作台、日历与资金预演
4. 复盘与备份管理

每一步都**先复用现有业务校验，再补工具**，并同时补上防串账号的测试。这样 MCP 不会变成一条绕过界面校验的旁路。
